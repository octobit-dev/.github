# octobit-dev

Pixel art tools built on one Rust engine.

**octo-lib** is a deterministic pixel art engine in Rust: one codebase for the browser (WebAssembly), Python, native apps and the `octo` command-line tool. It covers the document model, drawing tools, image to pixel art conversion, dithering, a quality linter with automatic fixes and file formats. Work on the first release has started.

**[OctoBit Studio](https://octobit.studio)** is a pixel art editor in the browser. It will move to the octo-lib engine.

No generative AI. Images come from people and from code that gives the same output for the same input.
