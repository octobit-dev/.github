# Security policy

## Reporting a vulnerability

Do not report security problems in public issues, discussions or pull requests.

Report them privately through GitHub:

1. Open the affected repository.
2. Go to the **Security** tab.
3. Click **Report a vulnerability**.

This creates a private security advisory that only you and the maintainers can see. Include the affected package and version, the impact and steps to reproduce.

## Supported versions

All libraries are before 1.0. Only the latest release of each package gets security fixes.
